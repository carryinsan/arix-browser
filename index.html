Privacy facts

Important limits, written plainly.

No account, analytics SDK, advertising SDK, or third-party frontend scripts are included. Arix does not intentionally upload your local bookmarks or history. Search text is sent to Arix's API and then to external search services to retrieve results. The API does not intentionally persist queries or cache search payloads.
Private tabs prevent Arix from saving that tab's browsing history in its local list. They do not make network requests anonymous or hide them from websites, search services, the hosting/network providers, or the underlying browser/operating system.

In-app browsing

Why some websites may not load here.

Websites can send security rules that forbid display inside an iframe. Only a full browser engine can load websites as a normal standalone browser; a web app cannot override a site's frame restrictions. Arix never silently opens a blocked website in another tab.
